# Animal illustrations

Twemoji graphics by Twitter, Inc. and other contributors, maintained by the
[Twemoji project](https://github.com/jdecked/twemoji), licensed under
[Creative Commons Attribution 4.0](LICENSE-GRAPHICS.txt).

These SVGs are unmodified upstream artwork, renamed to Brush Buddies animal IDs.
The pinned source commit, upstream code points and SHA-256 digests are recorded
in `source.json`. All artwork is bundled locally and cached for offline use;
no artwork is requested from a third-party server at runtime.
